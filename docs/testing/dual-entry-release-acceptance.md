   保留 Pages 开发域名和稳定正式 API，以及实际 COS 主机。开发工具不勾选“不校验合法域名…”。
2. 正式小程序关闭调试后选择聊天图片和 M4A，填写唯一验收感悟，提交；记录时间、设备、微信/基础库版本，
   在 ima 核对三项内容、录音播放和感悟。用验收昵称隔离真实成员；重复日需明确确认。
3. Chrome H5 用系统选择器完整提交，再从桌面微信拖入两份材料完整提交；拖拽不支持时保存到磁盘并选择。
   记录浏览器/桌面微信版本、文件字节大小、日期、结果截图、ima 内容核验。不要上传凭据或 HAR 中的秘密。
4. 对音频精确边界和边界+1做实际选择验证；真实大文件上传须提前告知耗时与媒体/存储副作用。
5. 异常分支需要可控测试环境/故障注入：读取不一致、COS 失败、finalize 回执丢失。
   不能通过猜测或仅断开整条网络证明已成功但回执丢失。重交应无新 prepare/PUT、同一 submission_id、返回 already，ima 不新增内容。
   正式环境不随意修改程序或强制重复登记；故障注入方案先确认，再执行。
6. 对拒绝路径采集请求结果与验收昵称相关的提交/KV/ima 前后差异；没有权限或无法观察时标为待验，不宣称零副作用。
